# Songs

Source for a songbook web site built with [MkDocs](https://www.mkdocs.org/) and the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme, published via GitHub Pages.

## Contents of this repo
* `Songs/` - The folder containing text files in [Markdown](https://www.markdownguide.org/cheat-sheet/) format . Each file becomes a page on the web-site.
* `Songs/README.md` - is the home page.
* `mkdocs.yml` - MkDocs config: site name, theme, markdown extensions, and plugins used to build the site from `Songs/`.
* `.github/workflows/gh-pages.yml` - GitHub Actions workflow that builds the site and deploys it to GitHub Pages on every push to the repository.
