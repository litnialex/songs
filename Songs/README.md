### About
This web site is a collection of dear to my heart songs, which I'm learning to sing.

The website is auto-generated from  simple text files in markdown format from the [repository](https://github.com/litnialex/songs). 

The songs have links to the sources and the author is specified whenever is possible. 

If you have any suggestions or questions you're welcome to contact me at  litnialex@gmail.com.
